# アーキテクチャ方針

## 目的

Pleasanter のカレンダー表示で休日を表示できるようにする。Google カレンダーのカレンダー ID と CSV から休日を取得し、CSS を生成して拡張スタイルとして配置する。

## 構成

```text
IHolidaySource  ─┐                     ┌─ FileStyleSink（ファイル配置）
 ├ GoogleCalendar ├→ Holiday[] → CssGenerator → StyleDefinition ─┤
 └ Csv            ┘                     └─ ApiStyleSink（Extensions API 登録）
```

- 取得元と配置先は interface で分け、CSS 生成は両方式で共通にする。
- 複数の取得元に同じ日付がある場合は後勝ち。CSV を最後に読むので、CSV で Google の名称や追加休日を上書きできる。
- CSS は日付順で決定的に出力する（差分が安定し、API 更新の要否も比較できる）。

## 配置方式

### ファイル配置（`generate`）

`App_Data/Parameters/ExtendedStyles/{Name}.json` を書き出す。本体の `ExtendedStyle` は `ExtendedBase` の `Name`・`Description`・`SiteIdList` などと `Style`（CSS 本文）を持つ。`SiteIdList` を省略すると全サイトに適用される。

### API 登録（`register`、未実装）

`/api/extensions/create`・`/api/extensions/{id}/update` で `ExtensionType: "Style"`、`ExtensionName`、`ExtensionSettings`、`Body`（CSS）を送る。同名の拡張があれば更新し、重複作成しない。API キーは環境変数から読む。

## 取得元

- Google カレンダーは公開 iCal（`https://calendar.google.com/calendar/ical/{ID}/public/basic.ics`）を使う。API キー・OAuth は不要で、公開カレンダーのみ対象。既定は日本の祝日カレンダー。複数 ID を指定できる。
- CSV は内閣府の `syukujitsu.csv` 形式（Shift_JIS・ヘッダー 1 行・`y/M/d`）をそのまま読む。UTF-8 も可。
- どちらも `/from`〜`/to`（既定: 今年と来年）の年で絞る。内閣府 CSV は 1955 年からあるため、絞らないと標準カレンダーの土日指定が膨らむ。

## CSS

標準カレンダーと FullCalendar の両方を 1 つの CSS で扱う。優先順位は記述順で、土曜 → 日曜・祝日の順（土曜の祝日は祝日の色）。前月・翌月のはみ出し日には色を付けない。

| | 標準カレンダー | FullCalendar |
| --- | --- | --- |
| 範囲 | `[id^="CalendarBody"]` | `[id^="FullCalendar"].calendar-container` |
| 日付 | `td.container[data-id="yyyy/M/d"]`（0 埋めなし） | `[data-date="yyyy-MM-dd"]` |
| 土日 | 日付ごとに指定（曜日クラスなし・週の開始曜日が設定で変わるため） | `.fc-day-sat` / `.fc-day-sun` |
| 除外 | `:not(.other-month)` | `:not(.fc-day-other)` |
| 祝日名 | 月表示 `.day::after` | `.fc-daygrid-day-top` / `.fc-col-header-cell-cushion` / `.fc-list-day-text` の `::after` |

標準カレンダーの年表示も `td.container` で `data-id` が月初日になるため、月表示は `:has(> div > .day)`、週表示は `.is-weekly` で限定する。
